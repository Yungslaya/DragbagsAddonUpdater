# ProfessionPal 1.4.3

- Added a minimap button. Left-click opens the guide, right-click opens Settings, and you can drag it around the edge of the minimap.
- Hide it with **Show the minimap button** in Settings, or type `/prof minimap`. It also hides while the Gathering HUD is up.
- A one-time chat message on login tells you how to open the guide.

Fully restart WoW after updating because this update adds a new addon file.
